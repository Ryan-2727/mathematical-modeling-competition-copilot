# Chinese Contest Paper Format 2025

Use this module only for Chinese mathematical modeling contests that follow the
2025 National College Student Mathematical Modeling Competition paper format
document supplied as `format2025.doc`. It is historical layout guidance, not a
2026 rule source. For CUMCM 2026, use `cumcm-2026-rules.md`: its abstract,
no-contents, 30-main-text-page, and unlimited-appendix rules take precedence.

If a local contest or provincial contest gives stricter rules, follow the stricter local rules while preserving the identity-removal, appendix, support-material, and electronic-submission rules below.

## Paper Version

- Use white A4 paper.
- Leave at least 2.5 cm margins on all four sides.
- Bind from the left.
- Page 1 is the commitment form.
- Page 2 is the number-only page.
- Do not alter the content or format of the commitment form or number-only page.
- Page 3 is the abstract page.
- Page 4 starts the main text.
- Do not include a table of contents.
- Try to keep the main text within 20 pages.
- Put appendices after the main text. Appendix page count is unlimited.
- Printed appendices must be bound together with the main text when a paper version is required.

## Abstract Page

- The abstract page is the first page of the electronic paper.
- The abstract content, including title and keywords, must fit on one page.
- Do not translate the Chinese abstract into English unless the contest separately requires it.
- Start page numbering from the abstract page.
- Use Arabic page numbers.
- Place page numbers in the center footer.

Recommended abstract order:

1. Problem and task scope.
2. Main model or method.
3. Key results by subproblem.
4. Validation, sensitivity, or robustness result.
5. Practical conclusion.
6. Keywords.

## Main Text

Use a contest-paper structure unless the statement gives a required template:

1. Problem restatement.
2. Assumptions.
3. Notation.
4. Data processing.
5. Model establishment and solution by subproblem.
6. Results and analysis.
7. Sensitivity or robustness analysis.
8. Strengths and weaknesses.
9. References.
10. Appendices.

Keep formula numbers, figure numbers, table numbers, units, and variable names consistent with code and results.

## Appendix Requirements

The appendix should include:

- a support-material file list
- all complete and runnable source code used for modeling
- Excel, SPSS, or other software interaction commands when they are part of the modeling workflow
- necessary intermediate outputs that support the paper but are too long for the main text

If no program was used, state exactly:

```text
本论文没有用到程序
```

If no support-material file is needed, state exactly:

```text
本论文没有支撑材料
```

Do not omit source code that is needed to reproduce the model. Missing source code, code that cannot run, or code results inconsistent with the paper can invalidate the submission.

## Electronic Paper

- Submit the paper as one standalone file.
- Use PDF or Word format; prefer PDF when no contest rule says otherwise.
- Keep the file size within 20 MB.
- Do not compress the electronic paper file.
- The electronic paper must match the paper version in content and format, including appendices, except that it must not include the commitment form or number-only page.
- The first page of the electronic paper must be the abstract page.

## Support Materials

Submit support materials as a separate compressed file when required:

- Use RAR or ZIP.
- Keep the archive within 20 MB.
- Include all necessary materials that support models, results, and conclusions.
- Include all runnable source code.
- Include independently collected data, excluding raw data already supplied by the contest problem.
- Include large intermediate tables or figures when they are needed for verification.
- Put the support-material file list in the paper appendix.
- Do not include the commitment form or number-only page.

## Identity And Compliance Rules

- The abstract page, main text, appendix, electronic paper, and support-material files must not reveal contestant identity, school, or competition region.
- Cite every public source, online source, borrowed method, dataset, or external result according to scientific paper norms.
- Mark citations in the main text where the source is used.
- Check the current competition rules for artificial intelligence tool use and record any required disclosure or compliance statement.

## Final Writing Gate

Before final verification, confirm:

- paper and electronic-paper page sequences are separated correctly
- no table of contents is present
- abstract is within one page
- main text is controlled near the 20-page target
- appendix contains source code or the required no-code statement
- support-material list matches the archive
- electronic paper excludes commitment and number pages
- identity information is absent from all submitted files
