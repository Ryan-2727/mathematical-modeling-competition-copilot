# Short Description

Self-contained Codex skill for mathematical modeling competitions: analyze the problem, design models, resolve literature details, run reproducible experiments, write the paper, and verify the final submission.

中文描述：一个自包含的数学建模竞赛 Codex skill，覆盖审题、建模、文献细节、代码实验、图表表格、论文撰写和最终核验。DOCX/PDF/XLSX/Notebook 等文件处理能力需要在 Codex 中安装或启用对应插件。
