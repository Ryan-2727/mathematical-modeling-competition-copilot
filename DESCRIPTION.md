# Short Description

Explicit-invocation-only, self-contained Codex skill for mathematical modeling competitions: analyze the problem, justify model choices against baselines, run reproducible and stress-tested experiments, write LaTeX papers with at least ten verified scholarly references, and deliver both the compiled PDF/source and a hashed code/data support package. It includes an optional user-approved post-paper award review and does not guarantee an award.
