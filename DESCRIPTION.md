# Short Description

Explicit-invocation-only, self-contained Codex skill for mathematical modeling competitions: analyze the problem, justify model choices against baselines, run reproducible and stress-tested experiments, write Chinese or English contest papers, and verify the final submission. It includes an optional user-approved post-paper award review and does not guarantee an award.

中文描述：一个仅限显式调用、自包含的数学建模竞赛 Codex skill，覆盖审题、基线与候选模型取舍、可复现计算、压力测试、图表表格、论文撰写和最终核验；完整论文完成后可经用户同意进入可选冲奖评审，但不承诺获奖。DOCX/PDF/XLSX/Notebook 等文件处理能力需要在 Codex 中安装或启用对应插件。
