# Short Description

Explicit-invocation-only, self-contained Codex skill for mathematical modeling competitions: lock current official rules, coordinate cumulative phase gates, justify model choices against baselines, run reproducible and stress-tested experiments, write LaTeX papers with at least ten hash-verified scholarly references, and separate the complete user delivery from the profile-safe official submission. It includes an optional user-approved post-paper award review and does not guarantee an award.
